# Joining the open Galleonaire TestFlight beta

The existing public invitation is https://testflight.apple.com/join/52fmzweP.
No developer redemption code is required through this invitation.

Install Apple's TestFlight app on the iPhone, then return to this invitation link
and open it again. Accept the Galleonaire invitation and choose Install. Simply
opening TestFlight after installing it may leave a person on its generic Redeem
Code screen; the public invitation must still be opened. If a messaging app does
not open the invitation properly, open the same link in the phone's web browser.

Galleonaire needs iOS 17 or later. Apple's platform/account eligibility requirements
still apply. Apple allows up to 10,000 external testers per app.

On 23 September 2026, at the user's request for open access, the optional 100-tester
cap was disabled and read back as publicLinkLimitEnabled=false. The saved numeric
value 100 is dormant while the limit is disabled. The group has no recruitment
criteria (relationship data=null). The existing link and tester memberships were
preserved. Build 16 remains available. Do not restore the former 100-person cap.

The app's public beta description now begins with these code-free joining steps,
and its saved value was verified directly with Apple. No new app build is needed.

A tester's exact code-screen cause has not been observed; installing TestFlight
without reopening the invitation is the likely explanation, not a proven diagnosis
for every affected person. Developers cannot remove Apple's generic Redeem UI.
