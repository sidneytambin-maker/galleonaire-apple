This is Sidney Tambin's personal project. Its storage folder is not branding.
Use the personal com.sidneytambin.galleonaire bundle family for the first release.

## Preferred free Apple build route

On 23 September 2026 Sidney explicitly authorised public GitHub repositories with
standard free Mac runners as the preferred route for Galleonaire and future Apple
builds, conditional on checking source history, build logs and artifacts for secrets
and information that must remain private. Repeat that check for each project.
Keep signing keys and credentials private. Do not enable paid runners or billing
without explicit approval. Use another free service if publication is unsuitable.

of actual TestFlight availability. A pushed commit is not a completed release.
